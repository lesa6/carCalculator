# carCalculator

**🚗 carCalculator
Калькулятор расхода на автомобиль. Разработан в рамках обучения по направлению Python-разработка.

🛠 Стек
Python 3.10+
pytest для тестирования
🚀 Запуск
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
pytest  # запуск тестов**
